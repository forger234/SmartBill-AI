
# SmartBill AI

An AI-powered Bill and Invoice Information Extraction System.

## Project Overview

SmartBill AI allows users to upload or capture bill images and automatically extract invoice information into structured JSON format.

## Features

- Bill image upload
- Camera-based bill capture
- OCR text extraction
- AI-powered information extraction
- Schema-constrained structured output
- Data validation
- Tabular result display
- JSON export

## Technology Stack

- Python
- LangChain
- Pydantic
- Gemini API
- PaddleOCR
- OpenCV
- Streamlit
- SQLite
